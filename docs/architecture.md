
# SmartCRM AI — Architecture

## 1. Project Overview
SmartCRM AI is an AI-powered Customer Relationship Management system.

## 2. Technology Stack

### Backend
- PHP 8.3
- Laravel 12
- MySQL
- Laravel Sanctum

### Frontend
- React
- TypeScript
- Vite
- React Router
- Recharts
- Lucide React

## 3. Application Architecture

React Frontend
    |
    | HTTP / JSON API
    |
Laravel Backend
    |
    | Eloquent ORM
    |
MySQL Database

## 4. Project Structure

- backend/ — Laravel API
- frontend/ — React application
- infra/ — Infrastructure and deployment
- docs/ — Project documentation

## 5. Authentication
Laravel Sanctum token-based authentication.

## 6. Security
- Environment variables for secrets
- API authentication
- Backend-side authorization
- Database validation
